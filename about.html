Who We Are

JobPortal is a simple static website created as a college mini project. The idea of this website is to show how a real job portal looks and works on the front-end side. Job seekers can browse jobs, read job details and fill an application form.

This project is built using only HTML5, CSS3, Bootstrap 5 and very basic JavaScript. There is no database and no backend, so all the job information on this website is written directly inside the HTML pages.

Our Mission
  • Help students find their first job
  • Show jobs from good companies
  • Keep the website simple and easy to use
  • Make the design fully responsive
