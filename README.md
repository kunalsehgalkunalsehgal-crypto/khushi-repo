# Job Portal Website (Static Mini Project)

A simple **static Job Portal website** made as a B.Sc. IT college mini project.
It shows job listings, job details and simple forms (Login, Register, Apply, Contact).

## Features

- Home page with hero section and latest jobs
- Jobs page with 8 sample job cards
- Job Details page with full job information
- Apply Job form with basic validation
- Login and Register pages with Show/Hide Password
- About Us page
- Contact Us page with contact form
- Fully responsive design (mobile, tablet, desktop)
- Same navbar and footer on every page

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5 (CDN)
- Bootstrap Icons (CDN)
- Google Font - Poppins
- Very basic JavaScript (form validation only)

There is **no backend, no database and no API**. All content is hardcoded.

## How to Run

1. Download or copy the `Job-Portal` folder.
2. Open the folder.
3. Double click on **index.html**.
4. The website opens in your browser. That's all - no installation needed.

## GitHub Pages Compatibility

This project works on GitHub Pages because it is 100% static:

1. Create a new GitHub repository.
2. Upload all the files and folders (keep `index.html` in the root).
3. Go to **Settings > Pages**.
4. Select branch `main` and folder `/ (root)`, then click Save.
5. Your website will be live at `https://your-username.github.io/repository-name/`.
